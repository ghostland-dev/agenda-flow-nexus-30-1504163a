# Agenda Flow (v2)

Second iteration of the Agenda Flow planner.

## Features

- Sortable task lists
- Calendar views
- Charts with Recharts

## Tech Stack

- Vite
- React
- TypeScript
- Tailwind CSS
- shadcn/ui (Radix UI)
- TanStack Query
- React Router

## Getting Started

```bash
git clone https://github.com/ghostland-dev/agenda-flow-v2.git
cd agenda-flow-v2
npm install
npm run dev
```

Other scripts:

- `npm run build`: vite build
- `npm run lint`: eslint .
- `npm run preview`: vite preview
